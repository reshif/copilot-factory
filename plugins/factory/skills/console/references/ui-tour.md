# Factory Console: what the page shows

Read this only when the user asks what the console shows, how to find something on it, or what a view, filter or key does.

- **The floor.** Five tiles (your turn, running, parked, stopped, done) that are also filters, filters with counts on the left, and a filter box that takes words and tokens such as `is:waiting`, `risk:high`, `recipe:bug@low`, `gate:H2`, `has:finding`, `has:rework`, `agent:builder`, `since:2d`.
- **Board.** One row per job, grouped by attention: stage lights, the step or the gate it waits at and for how long, agents running now by model, tasks, return trips, retries, inspector findings and recent activity. A red banner (and an `⚠ autopilot` flag in the header) says when Copilot's Autopilot was seen in this project: it could answer a gate for the user, so they should switch back to interactive mode.
- **Line map.** Every job as a transit line on one time axis: stations per step, double rings for gates, dashed while waiting on the user, red return trips, parks, ends and follow-up transfers.
- **The wire.** Everything that happened across all jobs, newest first, including hook errors, stop-gate blocks and Autopilot sightings. Click a line to open that job at that moment.
- **A job.** *Line* is the flow canvas with replay: stages are columns, time runs downward, going back is a red line labelled with why, and each row shows the agents (each with its tool calls, tokens and a link to its Copilot transcript, and its stderr when it failed), results, findings, replies and guard blocks. Below the line, a *Cost* panel shows the job's agent runs, agent time, tool calls, tokens and premium requests as the Copilot CLI reported them (— means not reported, not zero). *Story* tells the job in plain paragraphs (a serious finding the verifier could not settle reads as unverified and still blocking, with the verifier's evidence) and pins what it waits on with the exact reply to copy (e.g. `approve J-0004 H3`). *Tasks*, *Events* and *Lessons* too.
- **Recipe map** and **Crew**: the whole factory for any recipe, and every agent with its Copilot tools (from its agent file) and how often each ran.
- **Blueprint.** The same jobs as an engineering drawing set: sheet 1 the line (nine stations with their agent banks, return rails, side tracks, numbered callouts for each decision waiting on the user), then a projection globe, a matrix of stations by whose turn it is, a schedule with lead times, a parts list of agents and the general notes (lessons). A title block replays the whole history, counts *Your turn* as the Board does (lessons apart) and shows a *Gate safety* note while Autopilot was seen; clicking a job opens its section view with the reply to copy. Epics are not drawn there: the Notes drawer lists them and points to the Board.
- **Keys.** `j`/`k`, `Enter`, `Esc`, `/`, `⌘K` palette, `1`–`5`, `g w` (next job waiting for you), `g b` / `g l` / `g m` / `g c` / `g p` (board, line map, recipe map, crew, Blueprint), `?`. On the Blueprint, `/` finds a job (`Esc` clears it, then leaves it), `Esc` closes a section view and the arrow keys switch sheets.
